    Section Week 1 and Week 2

    The first two weeks of class focus on some prerequisite understanding necessary for our later conversations about functions and their analysis.
    🔗

    Subsection P1 Linear Modeling

    I can calculate a slope as a rate of change and use it with the point-slope equation of a line to model a linear relation between two variables.
    🔗
    What do I need to understand?
    • Conceptual: A slope is a proportionality constant relating the change in a dependent variable with respect to the change in an independent variable, usually written \(\Delta y = m \cdot \Delta x\text{,}\) where \(m\) represents the slope, \(\Delta x\) represents the increment of change in the independent variable \(x\text{,}\) and \(\Delta y\) represents the increment of change in the dependent variable \(y\text{.}\)
      🔗
      The variables \(x\) and \(y\) represent abstract placeholders for more physically relevant variables. you will need to be able to use other variables.
      🔗
      🔗
    • Computational: Calculate the slope between two points, \((x_1,y_1)\) and \((x_2,y_2)\) as
      \begin{equation*} m = \frac{\Delta y}{\Delta x} = \frac{y_2-y_1}{x_2-x_1}. \end{equation*}
      🔗
      🔗
    • Modeling: Although you likely currently feel most comfortable with the slope-intercept equation of a line \(y=mx+b\text{,}\) I am asking you to begin thinking in terms of the point-slope equation of a line given by \(y = y_1 + m \cdot(x-x_1)\) where \(m\) represents the known slope and \((x_1,y_1)\) represents a known point on the line.
      🔗
      This model of a line physically thinks through the process as follows. We know when \(x=x_1\text{,}\) the value of \(y\) starts at \(y=y_1\) (because it is on the line). As \(x\) changes to any other value, the value of \(y\) also changes, and the slope gives the proportional amount of change:
      \begin{align*} y \amp = y_1 + \Delta y \\ \amp = y_1 + m \cdot \Delta x \\ \amp = y_1 + m \cdot (x-x_1) \end{align*}
      🔗
      It is this idea that generalizes later in calculus to the idea of a definite integral measuring the change \(\Delta y\) when the rate of change or slope \(f'(t)\) is not constant:
      \begin{equation*} y = y_1 + \int_{x_1}^{x} f'(t) \, dt\text{.} \end{equation*}
      You are not expected to understand this bit yet -- it is a preview to the future.
      🔗
      🔗

    Subsection P2 Intervals and Set Operations

    I can translate a graphical representation of a set of numbers back and forth to interval notation and compute unions and intersections of multiple such sets.
    🔗
    What do I need to understand?
    • A collection of real numbers is a set. Simple sets with a finite number of values can be expressed using curly braces listing the numbers separated by commas, such as \(\{-3,2,5\}\text{,}\) which is a set including the values of -3, 2, and 5.
      🔗
      🔗
    • We often deal with sets formed by intervals, which are sets that include all of the values between two endpoints, and possibly the endpoints as well.
      🔗
      A single interval \((a,b)\text{,}\) where \(a\) and \(b\) represent any real numbers with \(a \lt b\) (or possibly \(-\infty\) or \(\infty\)), describes the set of values between \(a\) and \(b\text{.}\) It corresponds to the set of values \(x\) such that \(a \lt x \lt b\text{,}\) which in set constructor notation is
      \begin{equation*} (a,b) = \{x : a \lt x \lt b\}\text{.} \end{equation*}
      This type of interval where the endpoints are not included is called an open interval.
      🔗
      In order to describe an interval where the endpoint is included, we change the round parenthesis into a square bracket on the endpoint that is included.
      \begin{gather*} [a,b) = \{x : a \le x \lt b\} \\ (a,b] = \{x : a \lt x \le b\} \\ [a,b] = \{x : a \le x \le b\} \end{gather*}
      When both endpoints are included, the interval is called a closed interval.
      🔗
      🔗
    • The graphical representation of an interval is created by drawing a line segment between the endpoints, and marking the endpoints themselves with either open circles (if not included) or closed circles (if included). If the interval extends to infinity, instead of putting a circle on that end, we put an arrow to indicate it continues indefinitely.
      🔗
      🔗
    • When a set includes values coming from multiple disconnected or disjoint intervals, we describe the set as a union of the component intervals. A single isolated number \(a\) can also be included as a set \(\{a\}\text{.}\)
      🔗
      Suppose my set \(S\) has component intervals or isolated values that can be described individually as \(S_1\text{,}\) \(S_2\text{,}\) \(S_3\text{,}\) etc. Then we would write
      \begin{equation*} S = S_1 \cup S_2 \cup S_3 \cup \cdots \end{equation*}
      Using the union operation \(\cup\) creates a single set from many component pieces.
      🔗
      🔗
    • Given two sets \(A\) and \(B\text{,}\) the union is a new set \(A \cup B\) that consists of all values in at least one of the two sets (could be in just one or both).
      🔗
      Given two sets \(A\) and \(B\text{,}\) the intersection is a new set \(A \cap B\) that consists of all values in both the two sets (must be in both). This is the values in the overlap
      🔗
      After you identify the values in a set, you then identify the new component intervals and possible isolated values to rewrite the set using interval notation.
      🔗
      🔗
