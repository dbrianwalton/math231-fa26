    Handout Proving Limits with the Definition
    

    In “The Definition of a Limit” and “Limits as Error Tolerance” we found a working \(\delta\) for specific choices of \(\epsilon\text{.}\) A limit statement makes a stronger claim: a working \(\delta\) exists for every \(\epsilon \gt 0\text{.}\) This handout shows how to guarantee that by finding \(\delta\) as a formula in \(\epsilon\text{.}\)
    🔗

    What a Proof of a Limit Must Show.

    Definition 28 Limit.

    \(\displaystyle \lim_{x \to a} f(x) = L\) means that for every \(\epsilon \gt 0\) there exists a \(\delta \gt 0\) such that
    \begin{gather*} 0 \lt |x-a| \lt \delta \quad \text{implies} \quad |f(x)-L| \lt \epsilon\text{.} \end{gather*}
    🔗
    🔗
    To prove a limit statement, we start by assuming we are given \(\epsilon \gt 0\) as an arbitrary value. We need to state a specific way to find or guarantee we could find \(\delta \gt 0\text{,}\) which may depend on \(\epsilon\text{,}\) and show using this value of \(\delta\text{,}\) every value of \(x\) satisfying \(0 \lt |x-a| \lt \delta\) must guarantee \(|f(x)-L| \lt \epsilon\) is true.
    🔗

    Remark 29 Strategy.

    A proof states the value or method to find \(\delta\) as soon as we state we are given the value of \(\epsilon\text{.}\) In practice, we have to work backward on scratch paper. We start from the desired output inequality \(|f(x)-L| \lt \epsilon\) and rewrite it so that the expression \(|x-a|\) appears, usually by factoring. The value \(|x-a|\) is usually multiplied by some value or formula which we need to bound so that we get some multiple of \(\delta\text{.}\) We choose our value of \(\delta\) so that when multiplying by this bound we stay smaller than \(\epsilon\text{.}\) Then we return to the actual proof and proceed forward, beginning with \(\epsilon\text{,}\) stating \(\delta\text{,}\) assuming \(0 \lt |x-a| \lt \delta\) and ending with \(|f(x)-L| \lt \epsilon\text{.}\)
    🔗
    🔗
    🔗

    Worked Examples.

    Example 30 A Linear Function.

    Prove \(\displaystyle \lim_{x \to 2} (2x+3) = 7\text{.}\)
    🔗
    Solution.
    Scratch work. We want \(|(2x+3)-7| \lt \epsilon\text{.}\) Simplifying the left side means we want \(|2x-4| = 2|x-2| \lt \epsilon\text{.}\) We will be choosing \(\delta\) and know that \(|x-2| \lt \delta\text{,}\) which will then be multiplied by 2. This suggests we want \(\delta = \frac{\epsilon}{2}\text{.}\)
    🔗

    Proof.
    Let \(\epsilon \gt 0\) and choose \(\delta = \frac{\epsilon}{2}\text{.}\) If \(0 \lt |x-2| \lt \delta\text{,}\) then
    \begin{align*} |(2x+3)-7| \amp = 2|x-2|\\ \amp \lt 2\delta\\ \amp = \epsilon\text{.} \end{align*}
    Since \(\epsilon\) was arbitrary, the limit statement is true.
    🔗
    🔗
    🔗
    🔗

    Example 31 A Quadratic Function.

    Prove \(\displaystyle \lim_{x \to 2} x^2 = 4\text{.}\)
    🔗
    Solution.
    Scratch work. We want \(|x^2-4| \lt \epsilon\text{.}\) Factoring gives \(|x-2|\,|x+2| \lt \epsilon\text{.}\) The factor \(|x+2|\) is not constant, so we bound it. If we require \(\delta \lt 1\text{,}\) then we will work with \(|x-2| \lt 1\text{,}\) then \(1 \lt x \lt 3\) and \(3 \lt x+2 \lt 5\text{,}\) so \(|x+2| \lt 5\text{.}\) Then \(|x-2|\,|x+2| \lt 5|x-2|\text{,}\) and we need \(5|x-2| \le \epsilon\text{.}\) This suggests we also need \(\delta \lt \frac{\epsilon}{5}\text{.}\) We meet both of our requirements by choosing \(\delta = \min\left(1, \frac{\epsilon}{5}\right)\text{.}\)
    🔗

    Proof.
    Let \(\epsilon \gt 0\) and choose \(\delta = \min\left(1, \frac{\epsilon}{5}\right)\text{.}\) If \(0 \lt |x-2| \lt \delta\text{,}\) we know that \(|x-2| \lt 1\) and \(|x-2| \lt \frac{\epsilon}{5}\text{.}\) Because \(|x-2| \lt 1\text{,}\) we know \(|x+2| \lt 5\text{.}\) Together, we now know
    \begin{align*} |x^2-4| \amp = |x-2|\,|x+2|\\ \amp \le \frac{\epsilon}{5} \cdot 5 = \epsilon\text{.} \end{align*}
    Since \(\epsilon\) was arbitrary, the limit statement is true.
    🔗
    🔗
    🔗
    🔗
    🔗

    From Proofs to Rules.

    The two examples above each ended with a formula for \(\delta\) in terms of \(\epsilon\text{.}\) Such a formula is an \(\epsilon\)-\(\delta\) rule: a recipe that takes any tolerance \(\epsilon \gt 0\) and returns a precision \(\delta \gt 0\) that works. When we know \(\displaystyle \lim_{x \to a} f(x) = L\text{,}\) we know that some \(\epsilon\)-\(\delta\) rule exists for \(f\text{.}\)
    🔗
    We will now prove the limits of the simplest functions directly, and then show how the \(\epsilon\)-\(\delta\) rules of the pieces build a rule for combinations. This turns the definition of limits into a collection of limit rules.
    🔗
    🔗

    Limits of Elementary Functions.

    Theorem 32 Limit of a Constant.

    For any constant \(c\text{,}\) \(\displaystyle \lim_{x \to a} c = c\text{.}\)
    🔗
    🔗

    Proof.
    Let \(\epsilon \gt 0\text{.}\) Any positive \(\delta\) works, so choose \(\delta = 1\text{.}\) If \(0 \lt |x-a| \lt \delta\text{,}\) then \(|c-c| = 0 \lt \epsilon\text{.}\)
    🔗
    🔗

    Theorem 33 Limit of the Identity Function.

    \(\displaystyle \lim_{x \to a} x = a\text{.}\)
    🔗
    🔗

    Proof.
    Let \(\epsilon \gt 0\) and choose \(\delta = \epsilon\text{.}\) If \(0 \lt |x-a| \lt \delta\text{,}\) then \(|x-a| \lt \epsilon\text{.}\)
    🔗
    🔗

    Theorem 34 Limit of a Linear Function.

    For constants \(m \ne 0\) and \(b\text{,}\) \(\displaystyle \lim_{x \to a} (mx+b) = ma+b\text{.}\)
    🔗
    🔗

    Proof.
    Let \(\epsilon \gt 0\) and choose \(\delta = \frac{\epsilon}{|m|}\text{.}\) If \(0 \lt |x-a| \lt \delta\text{,}\) then
    \begin{align*} |(mx+b)-(ma+b)| \amp = |m|\,|x-a|\\ \amp \lt |m|\delta\\ \amp = \epsilon\text{.} \end{align*}
    🔗
    🔗

    Remark 35 Continuity.

    In each of these results the value of the limit is the same as the value of the function at \(x=a\text{.}\) For the constant function \(f(x)=c\) the value is \(c\text{,}\) for the identity function the value is \(a\text{,}\) and for the linear function the value is \(ma+b\text{.}\) This means that these elementary functions are continuous at every point \(a\text{.}\)
    🔗
    🔗
    🔗

    Limits of Combinations.

    In each rule below, assume the limits of the pieces are known, so each piece has its own \(\epsilon\)-\(\delta\) rule. The remark after each rule states how to produce a \(\delta\) for the combination from those rules, and the proof shows that it works.
    🔗

    Theorem 36 Limit of a Scalar Multiple.

    If \(\displaystyle \lim_{x \to a} f(x) = L\) and \(k \ne 0\) is a constant, then \(\displaystyle \lim_{x \to a} \left[k f(x)\right] = kL\text{.}\)
    🔗
    🔗

    Remark 37 Finding \(\delta\).

    Given \(\epsilon\text{,}\) use the \(\epsilon\)-\(\delta\) rule for \(f(x)\) with the tolerance \(\frac{\epsilon}{|k|}\) to get \(\delta\text{.}\)
    🔗
    🔗

    Proof. (Theorem 36)
    Let \(\epsilon \gt 0\text{.}\) Because \(\displaystyle \lim_{x \to a} f(x) = L\text{,}\) choose \(\delta\) so that if \(0 \lt |x-a| \lt \delta\text{,}\) then \(|f(x)-L| \lt \frac{\epsilon}{|k|}\text{.}\) Consequently,
    \begin{align*} |k f(x) - kL| \amp = |k|\,|f(x)-L|\\ \amp \lt |k| \cdot \frac{\epsilon}{|k|}\\ \amp = \epsilon\text{.} \end{align*}
    🔗
    🔗

    Example 38 Buying Snacks.

    You and a friend are buying snacks. You are supposed to buy \(\$3\) of snacks and your friend is supposed to buy \(\$3\) of snacks, but prices vary slightly so it is hard to be exact. You agree in advance that you will each stay within \(\$0.10\) of your target. How far away can the total combined cost be from \(\$6\text{?}\)
    🔗
    Solution.
    Each of you are going to be spending a value between $2.90 and $3.10. The cheapest scenario is that you each spend $2.90 for a total cost of $5.80. The most expensive scenario results in a total cost of $6.20. The total error can be as large as $0.20.
    🔗
    🔗
    🔗

    Theorem 39 Triangle Inequality.

    For any values \(A\) and \(B\text{,}\) \(|A+B| \le |A| + |B|\text{.}\)
    🔗
    🔗
    In the snack example, let \(x\) be your cost and \(y\) be your friend’s cost. The agreement says \(|x-3| \lt 0.10\) and \(|y-3| \lt 0.10\text{.}\) The distance of the total from \(\$6\) is
    \begin{align*} |(x+y)-6| \amp = |(x-3)+(y-3)|\\ \amp \le |x-3| + |y-3|\\ \amp \lt 0.10 + 0.10 = 0.20\text{.} \end{align*}
    🔗

    Theorem 40 Limit of a Sum.

    If \(\displaystyle \lim_{x \to a} f(x) = L\) and \(\displaystyle \lim_{x \to a} g(x) = M\text{,}\) then \(\displaystyle \lim_{x \to a} \left[f(x)+g(x)\right] = L+M\text{.}\)
    🔗
    🔗

    Remark 41 Finding \(\delta\).

    Given \(\epsilon\text{,}\) use the \(\epsilon\)-\(\delta\) rule for \(f(x)\) with the tolerance \(\frac{\epsilon}{2}\) to get \(\delta_1\text{.}\) Use the \(\epsilon\)-\(\delta\) rule for \(g(x)\) with the tolerance \(\frac{\epsilon}{2}\) to get \(\delta_2\text{.}\) The rule for the sum uses \(\delta = \min(\delta_1, \delta_2)\text{.}\)
    🔗
    🔗

    Proof. (Theorem 40)
    Let \(\epsilon \gt 0\text{.}\) Because \(\displaystyle \lim_{x \to a} f(x)=L\text{,}\) choose \(\delta_1\) so that if \(0 \lt |x-a| \lt \delta_1\text{,}\) \(|f(x)-L| \lt \frac{\epsilon}{2}\text{.}\) Because \(\displaystyle \lim_{x \to a} g(x)=M\text{,}\) choose \(\delta_2\) so that if \(0 \lt |x-a| \lt \delta_2\text{,}\) \(|g(x)-M| \lt \frac{\epsilon}{2}\text{.}\) Let \(\delta = \min(\delta_1, \delta_2)\text{.}\) If \(0 \lt |x-a| \lt \delta\text{,}\) then \(|x-a| \lt \delta_1\) and \(|x-a| \lt \delta_2\text{,}\) so \(|f(x)-L| \lt \frac{\epsilon}{2}\) and \(|g(x)-M| \lt \frac{\epsilon}{2}\text{.}\) By the triangle inequality with \(A = f(x)-L\) and \(B = g(x)-M\text{,}\)
    \begin{align*} |(f(x)+g(x))-(L+M)| \amp = |(f(x)-L)+(g(x)-M)|\\ \amp \le |f(x)-L| + |g(x)-M|\\ \amp \lt \frac{\epsilon}{2} + \frac{\epsilon}{2}\\ \amp = \epsilon\text{.} \end{align*}
    🔗
    🔗

    Theorem 42 Limit of a Product.

    If \(\displaystyle \lim_{x \to a} f(x) = L\) and \(\displaystyle \lim_{x \to a} g(x) = M\text{,}\) then \(\displaystyle \lim_{x \to a} \left[f(x)\,g(x)\right] = LM\text{.}\)
    🔗
    🔗

    Remark 43 Finding \(\delta\).

    Given \(\epsilon\text{,}\) use the \(\epsilon\)-\(\delta\) rule for \(f(x)\) with the tolerance \(\min\left(1, \frac{\epsilon}{2(|M|+1)}\right)\) to get \(\delta_1\text{.}\) Use the \(\epsilon\)-\(\delta\) rule for \(g(x)\) with the tolerance \(\frac{\epsilon}{2(|L|+1)}\) to get \(\delta_2\text{.}\) The rule for the product uses \(\delta = \min(\delta_1, \delta_2)\text{.}\)
    🔗
    🔗

    Proof. (Theorem 42)
    Let \(\epsilon \gt 0\text{.}\) We will be rewriting \(f(x)g(x) - LM\) so that we replace one function by its limit at a time:
    \begin{align*} |f(x)g(x) - LM| \amp = |f(x) g(x) - f(x) M + f(x) M - LM |\\ \amp = |f(x) \big(g(x) - M\big) + \big(f(x)-L\big) M|\\ \amp \le |f(x)| \, |g(x)-M| + |f(x)-L| \, |M| \end{align*}
    If \(|f(x)-L| \lt 1\text{,}\) then \(|f(x)| \lt |L| + 1\text{.}\) If we also have \(|g(x)-M| \lt \frac{\epsilon/2}{|L|+1}\text{,}\) then \(|f(x)| \, |g(x)-M| \lt \frac{\epsilon}{2}\text{.}\) Similarly, if \(|f(x)-L| \lt \frac{\epsilon/2}{|M|+1}\text{,}\) then \(|f(x)-L| \, |M| \lt \frac{\epsilon}{2}\text{.}\)
    🔗
    Because \(\lim_{x \to a} f(x)=L\text{,}\) choose \(\delta_1 \gt 0\) so that if \(0 \lt |x-a| \lt \delta_1\text{,}\) then \(|f(x)-L| \lt \min(1, \frac{\epsilon/2}{|M|+1})\text{.}\) Because \(\lim_{x \to a} g(x)=M\text{,}\) choose \(\delta_2 \gt 0\) so that if \(0 \lt |x-a| \lt \delta_2\text{,}\) then \(|g(x)-M| \lt \frac{\epsilon/2}{|L|+1})\text{.}\) Let \(\delta = \min(\delta_1, \delta_2)\) and assume \(0 \lt |x-a| \lt \delta\text{.}\) This guarantees
    \begin{align*} |f(x)-L| \amp \lt 1\\ |f(x)-L| \amp \lt \frac{\epsilon}{2(|M|+1)}\\ |g(x)-M| \amp \lt \frac{\epsilon}{2(|L|+1)}\text{.} \end{align*}
    Consequently,
    \begin{align*} |f(x)g(x)-LM| \amp \le |f(x)|\,|g(x)-M| + |M|\,|f(x)-L|\\ \amp \lt (|L|+1)\cdot\frac{\epsilon}{2(|L|+1)} + |M|\cdot\frac{\epsilon}{2(|M|+1)}\\ \amp \le \frac{\epsilon}{2} + \frac{\epsilon}{2}\\ \amp = \epsilon\text{.} \end{align*}
    🔗
    🔗

    Theorem 44 Limit of a Reciprocal.

    If \(\displaystyle \lim_{x \to a} f(x) = L\) and \(L \ne 0\text{,}\) then \(\displaystyle \lim_{x \to a} \frac{1}{f(x)} = \frac{1}{L}\text{.}\)
    🔗
    🔗

    Remark 45 Finding \(\delta\).

    Given \(\epsilon\text{,}\) use the \(\epsilon\)-\(\delta\) rule for \(f(x)\) with the tolerance \(\min\left(\frac{|L|}{2}, \frac{\epsilon L^2}{2}\right)\) to get \(\delta\text{.}\)
    🔗
    🔗

    Proof. (Theorem 44)
    Let \(\epsilon \gt 0\text{.}\) Because \(\displaystyle \lim_{x \to a}f(x) = L\text{,}\) choose \(\delta \gt 0\) so that \(|f(x)-L| \lt \min\left(\frac{|L|}{2}, \frac{\epsilon L^2}{2}\right)\) whenever \(0 \lt |x-a| \lt \delta\text{.}\)
    🔗
    Now assume \(0 \lt |x-a| \lt \delta\text{.}\) Because \(|f(x)-L| \lt \frac{|L|}{2}\text{,}\) we get \(|f(x)| \gt \frac{|L|}{2}\) using the triangle inequality: \(|L| = |f(x) + (L-f(x))| \le |f(x)| + |L-f(x)|\text{,}\) so
    \begin{align*} |f(x)| \amp \ge |L| - |L-f(x)|\\ \amp \gt |L| - \frac{|L|}{2}\\ \amp = \frac{|L|}{2}\text{.} \end{align*}
    In particular \(f(x) \ne 0\text{,}\) and \(\frac{1}{|f(x)|} \lt \frac{2}{|L|}\text{.}\) Because we also have \(|f(x)-L| \lt \frac{\epsilon L^2}{2}\text{,}\)
    \begin{align*} \left|\frac{1}{f(x)}-\frac{1}{L}\right| \amp = \frac{|L-f(x)|}{|f(x)|\,|L|}\\ \amp \lt \frac{\epsilon L^2}{2}\cdot\frac{2}{|L|}\cdot\frac{1}{|L|}\\ \amp = \epsilon\text{.} \end{align*}
    🔗
    🔗

    Theorem 46 Limit of a Quotient.

    If \(\displaystyle \lim_{x \to a} f(x) = L\) and \(\displaystyle \lim_{x \to a} g(x) = M\) and \(M \ne 0\text{,}\) then \(\displaystyle \lim_{x \to a} \frac{f(x)}{g(x)} = \frac{L}{M}\text{.}\)
    🔗
    🔗

    Remark 47 No Need for \(\delta\).

    This theorem can actually be proved based on earlier rules rather than requiring that we use the \(\epsilon\)-\(\delta\) rules for limits because a quotient \(f(x)/g(x)\) is the same as a product of \(f(x)\) with a reciprocal \(1/g(x)\text{.}\)
    🔗
    🔗

    Proof.
    Because \(\lim_{x \to a} g(x) = M\) and \(M \ne 0\text{,}\) the limit rule for a reciprocal guarantees \(\lim_{x \to a} \frac{1}{g(x)} = \frac{1}{M}\text{.}\) Then since \(\frac{f(x)}{g(x)} = f(x) \cdot \frac{1}{g(x)}\) and \(\lim_{x \to a} f(x) = L\text{,}\) we can use the limit rule of products to know
    \begin{equation*} \lim_{x \to a} \frac{f(x)}{g(x)} = \lim_{x \to a} f(x) \cdot \frac{1}{g(x)} = L \cdot \frac{1}{M} = \frac{L}{M} \end{equation*}
