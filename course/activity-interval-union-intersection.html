    Worksheet Union and Intersection of Intervals
    

    Today’s problems are ordered so that you meet one new wrinkle at a time instead of all at once. We will start with clearly overlapping intervals to get the mechanics down, then look closely at what happens when two intervals share a single boundary point, then at intervals with a genuine gap between them. After that we will chain three sets together, and finish by intersecting two sets that are each already written as a union of two intervals.
    🔗
    Sketch each set on a number line before you write down an answer — it will save you from the most common mistakes.
    🔗

    1. Section 1 — Warm-Up: Clearly Overlapping Intervals.

    For each pair below, find \(A \cup B\) and \(A \cap B\text{.}\)
    🔗

    (a) Problem 1.

    \(A = [1,5]\text{,}\) \(B = [3,8]\)
    🔗
    🔗

    (b) Problem 2.

    \(A = (0,6)\text{,}\) \(B = (2,10)\)
    🔗
    🔗

    (c) Problem 3.

    \(A = [-3,2]\text{,}\) \(B = [-1,4]\)
    🔗
    🔗

    (d) Problem 4.

    \(A = [2,9]\text{,}\) \(B = [-1,5]\)
    🔗
    🔗
    🔗

    2. Section 2 — Adjacent Intervals: The Endpoint Decides Everything.

    Each of the four pairs below uses the same two numbers as endpoints — only whether each set includes or excludes the shared value \(4\) changes. Sketch each pair on a number line before answering. For each pair, find \(A \cap B\) and \(A \cup B\text{,}\) and answer: can the union be written as a single interval? Why or why not?
    🔗

    (a) Problem 5.

    \(A = [1,4]\text{,}\) \(B = [4,7]\) (both closed at \(4\))
    🔗
    🔗

    (b) Problem 6.

    \(A = [1,4)\text{,}\) \(B = [4,7]\) (open at \(4\) in \(A\text{,}\) closed at \(4\) in \(B\))
    🔗
    🔗

    (c) Problem 7.

    \(A = [1,4]\text{,}\) \(B = (4,7)\) (closed at \(4\) in \(A\text{,}\) open at \(4\) in \(B\))
    🔗
    🔗

    (d) Problem 8.

    \(A = (1,4)\text{,}\) \(B = (4,7)\) (both open at \(4\))
    🔗
    🔗

    (e) Discussion.

    In Problem 5, the intersection is not empty, but it is not a normal interval either — what is it?
    🔗
    In Problem 8, the union is missing only one point — why does that single missing point stop it from being written as one interval?
    🔗
    🔗
    🔗

    3. Section 3 — True Gaps: Non-Overlapping Intervals.

    For each pair below, find \(A \cap B\) and \(A \cup B\text{.}\)
    🔗

    (a) Problem 9.

    \(A = [1,3]\text{,}\) \(B = [5,8]\)
    🔗
    🔗

    (b) Problem 10.

    \(A = (-\infty, -2]\text{,}\) \(B = [0, \infty)\)
    🔗
    🔗

    (c) Problem 11.

    \(A = [0,2]\text{,}\) \(B = [2.5, 4]\)
    🔗
    🔗
    🔗

    4. Section 4 — Chaining It Together.

    Build the union of the first three sets, then intersect that result with the last set.
    🔗

    (a) Problem 12.

    \(A=[0,3]\text{,}\) \(B=[2,5]\text{,}\) \(C=[7,9]\text{,}\) \(D=[1,8]\text{.}\) Find \((A \cup B \cup C) \cap D\text{.}\)
    🔗
    🔗

    (b) Problem 13.

    \(A=[-4,-1]\text{,}\) \(B=[-2,3]\text{,}\) \(C=[6,10]\text{,}\) \(D=(-3,8)\text{.}\) Find \((A \cup B \cup C) \cap D\text{.}\)
    🔗
    🔗
    🔗

    5. Section 5 — Capstone: Intersecting Two Compound Sets.

    When \(S = A \cup B\) and \(T = C \cup D\text{,}\) distribute:
    \begin{equation*} S \cap T = (A \cap C) \cup (A \cap D) \cup (B \cap C) \cup (B \cap D). \end{equation*}
    Compute all four pairwise intersections (some will be empty), then combine and simplify.
    🔗

    (a) Problem 14 (warm-up — \(T\) is a single interval).

    \(S=[0,4] \cup [10,14]\text{,}\) \(T=[3,12]\text{.}\) Find \(S \cap T\text{.}\)
    🔗
    🔗

    (b) Problem 15.

    \(S=[-5,-1] \cup [2,6]\text{,}\) \(T=[-3,4] \cup [5,10]\text{.}\) Find \(S \cap T\text{.}\)
    🔗
    🔗

    (c) Problem 16.

    \(S=[1,5] \cup [7,10]\text{,}\) \(T=[4,8] \cup [9,12]\text{.}\) Find \(S \cap T\text{.}\)
    🔗
    🔗

    (d) Problem 17 — Challenge.

    \(S=[0,4] \cup [8,12]\text{,}\) \(T=[4,6] \cup [10,14]\text{.}\) Find \(S \cap T\text{.}\) (One of the four pairwise pieces is not an interval at all — what is it?)
    🔗
    🔗
    🔗

    6. Section 6 — Build-Your-Own (Paired Activity).

    Write your own set \(M\) as a union of two intervals of your choosing, aiming to include at least one interesting boundary. Trade with a partner and compute \(M \cap N\) together.
    🔗

    (a) Your set.

    Write your set \(M\) here.
    🔗
    🔗

    (b) With your partner.

    Compute \(M \cap N\) together. How many pieces does your intersection have? Could you have chosen your intervals so that the intersection was \(\varnothing\text{?}\) So that it was a single point?
