    Worksheet Domain of a Function
    

    A function is a rule for creating a single, unique output for each input value. But a rule does not automatically make sense for every possible input. The domain of a function is the set of input values for which the rule actually produces an output.
    🔗
    Today you will find the domain of a function three ways: by reading a graph carefully, by noticing which algebraic operations can fail to produce a real number, and by combining more than one restriction into a single set. Along the way, you will also spend a few minutes making reviewing how to evaluate a piecewise formula.
    🔗

    1. Section 1: Warm-Up: Evaluating a Piecewise Formula.

    Recall the piecewise function \(h\) from last class,
    \begin{equation*} h(x) = \begin{cases} x^2 - 1, & x \lt 1 \\ 1 - x, & x \ge 1 \end{cases} \end{equation*}
    Evaluating \(h\) always starts the same way. Decide which condition the input satisfies, and only then substitute into that piece’s formula.
    🔗

    (a)

    Find \(h(-3)\text{.}\)
    🔗
    🔗

    (b)

    Find \(h(1)\text{.}\) Which rule did you use, and why?
    🔗
    🔗

    (c)

    Find \(h(4)\text{.}\)
    🔗
    🔗

    (d)

    Recall the graph of \(f\) from last class. At \(x=-2\text{,}\) there was an open point at \((-2,3)\) and a separate closed point at \((-2,4)\text{.}\) Explain how deciding which of those two points actually belongs to \(f(-2)\) is the same kind of decision as deciding which piece of \(h\) to use when evaluating \(h(1)\text{.}\) What do you check first in each case?
    🔗
    🔗

    2. Section 2: Domain from a Graph.

    Here is the graph of a function \(k\text{.}\)
    🔗
    The dashed vertical line at \(x=-2\) is not part of the graph of \(k\text{.}\) It is only a visual marker showing where the curve is undefined: as \(x\) gets closer to \(-2\text{,}\) the two branches shoot off toward positive or negative infinity, so there is no single point to plot there at all. Compare that to the open circle at \((2, 0.25)\text{:}\) at \(x=2\) there is a specific value the curve would reach, \(0.25\text{,}\) but it has been deliberately left out; it’s a hole. The graph is only drawn for \(x\) between \(-5\) and \(5\text{;}\) it continues in the same way beyond that window on either side.
    🔗

    (a)

    State the domain of \(k\) using interval notation.
    🔗
    🔗

    (b)

    The dashed line at \(x=-2\) and the open circle at \(x=2\) both mark values excluded from the domain of \(k\text{,}\) but they are drawn differently. Explain what is different about what’s happening at each location.
    🔗
    🔗
    🔗

    3. Section 3: Domain from a Formula: Division by Zero.

    You have already seen that a root of a denominator factor corresponds to a vertical asymptote. That is often true, but not always: if the same factor also appears in the numerator and cancels, that root shows up as a hole instead. Either way, the input is excluded from the domain, since the original, unsimplified formula is not defined there.
    🔗
    We find these restrictions by solving an equation: set the denominator equal to zero and solve for \(x\text{.}\)
    🔗

    (a)

    Find the domain of \(p(x) = \dfrac{x+1}{x-3}\text{.}\)
    🔗
    🔗

    (b)

    Find the domain of \(q(x) = \dfrac{3}{x^2 - x - 6}\text{.}\) You will need to factor the denominator first.
    🔗
    🔗

    (c)

    Consider \(r(x) = \dfrac{(x-2)(x+4)}{(x-2)(x-5)}\text{.}\)
    🔗
    1. Find the domain of \(r\) directly from this original form, before simplifying anything.
      🔗
      🔗
    2. Now cancel the common factor \((x-2)\) to get \(\dfrac{x+4}{x-5}\text{.}\) A student looks at this simplified form and says the domain only needs to exclude \(x=5\text{.}\) Explain what went wrong.
      🔗
      🔗
    3. Which of the two excluded \(x\)-values would appear as a hole in the graph of \(r\text{,}\) and which would appear as a vertical asymptote?
      🔗
      🔗
    🔗
    🔗

    4. Section 4: Domain from a Formula: Square Roots.

    A square root only produces a real number when the expression underneath it is not negative. Finding this restriction means solving an inequality, so remember that multiplying or dividing both sides by a negative number flips the inequality’s direction.
    🔗

    (a)

    Find the domain of \(s(x) = \sqrt{-3x+6}\text{.}\)
    🔗
    The input of the square root is the formula \(-3x+6\text{.}\) Create and then solve an inequality that this formula is positive or zero.
    🔗
    🔗

    (b)

    Find the domain of \(t(x) = \sqrt{x^2 - x - 6}\text{.}\) What inequality is needed this time?
    🔗
    🔗
    🔗

    5. Section 5: Combining Restrictions.

    Some formulas have more than one restriction at once. To find the domain of a function like this, find the set of \(x\)-values allowed by each restriction separately, in interval notation. The domain of the whole function is the set of \(x\)-values that satisfy every restriction at the same time: the intersection of those sets.
    🔗
    (Equivalently, you could collect every \(x\)-value that causes a problem for any restriction, take the union of those bad sets, and then find its complement. Either method gives the same answer.) This is the same interval intersection and union work from earlier this term, just applied to domain restrictions instead of solved inequalities.
    🔗

    (a)

    Consider \(u(x) = \dfrac{\sqrt{x-2}}{x-6}\text{.}\)
    🔗
    1. Write the set of \(x\)-values allowed by the square root alone, in interval notation.
      🔗
      🔗
    2. Write the set of \(x\)-values allowed by avoiding division by zero alone.
      🔗
      🔗
    3. Combine these to find the domain of \(u\text{,}\) using interval notation.
      🔗
      🔗
    🔗
