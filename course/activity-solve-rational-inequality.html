    Worksheet Solving Rational Inequalities
    

    You now know how to create a sign analysis summary of polynomials and rational expressions when they are written in factored form. This allows us to solve inequalities involving polynomials and rational expressions when they can be factored.
    🔗

    1. Section 1: A polynomial inequality.

    When an expression is already factored and simplified, we know how to create a sign analysis summary number line:
    1. Find the root of each factor and mark it on a number line. These will be the end-points of our sign intervals.
      🔗
      🔗
    2. Determine the sign inside each of the intervals. You can use test points with the expression for each interval or you can find one interval and then use even/odd power analysis to get the rest.
      🔗
      🔗
    🔗
    Solving an inequality which is comparing an expression to zero is exactly the same as identifying positive and negative intervals, just with an added interpretation step.
    • \(\mathrm{expression} > 0\) is finding the set of values where the expression is positive.
      🔗
      \(\mathrm{expression} \ge 0\) is finding the set of values where the expression is positive and also any values where the expression equals zero.
      🔗
      🔗
    • Similar ideas apply to \(\mathrm{expression} < 0\) and \(\mathrm{expression} \le 0\text{,}\) except we are looking at sets where the expression is negative.
      🔗
      🔗
    🔗

    (a)

    Solve the inequality \(\displaystyle (x+1)^2(x-3) < 0\) using the following steps.
    • Create the number line summary of the sign analysis for the expression.
      🔗
      🔗
    • Because the inequality involves “\(< 0\)”, identify all of the values on the sign summary that make the expression negative. Since this is a strict inequality, the roots themselves are not included.
      🔗
      🔗
    • Write the set using interval notation.
      🔗
      🔗
    🔗
    🔗
    🔗

    2. Section 2: A polynomial inequality with three roots.

    Now try the same process on a polynomial with three distinct linear factors, this time using an “or equals” inequality.
    🔗

    (a)

    Solve the inequality \(\displaystyle x(x+2)(x-3) \ge 0\) using the following steps.
    • Create the number line summary of the sign analysis for the expression.
      🔗
      🔗
    • Because the inequality involves “\(\ge 0\)”, identify all of the values on the sign summary that make the expression positive or equal to zero. Since every factor is in the numerator, all three roots are included in the solution.
      🔗
      🔗
    • Write the set using interval notation.
      🔗
      🔗
    🔗
    🔗
    🔗

    3. Section 3: A rational inequality.

    A rational expression introduces a small complication: a factor in the denominator gives a vertical asymptote instead of a root. It still marks the end of a sign interval on the number line, but it is never part of the solution set, even when the inequality includes “or equals”.
    🔗
    It is essential that you pay attention to the difference between roots and vertical asymptotes (or other discontinuities) because the or equals part of an inequality only involves the roots, not the asymptotes.
    🔗

    (a)

    Solve the inequality \(\displaystyle \frac{(x+2)(x-1)^2}{x-3} \ge 0\) using the following steps.
    • Create the number line summary of the sign analysis for the expression.
      🔗
      🔗
    • Because the inequality involves “\(\ge 0\)”, identify all of the values on the sign summary that make the expression positive or equal to zero.
      🔗
      🔗
    • Write the set using interval notation.
      🔗
      🔗
    🔗
    🔗

    (b)

    Solve the inequality \(\displaystyle \frac{(x+2)(x-1)^2}{x-3} \lt 0\text{.}\) You already created the sign analysis summary for the same expression on the last problem. Only the interpretation is different.
    🔗
    🔗

    (c)

    Solve the inequality \(\displaystyle \frac{(x+2)(x-1)^2}{x-3} \le 0\text{.}\)
