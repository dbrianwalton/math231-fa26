    Worksheet Inverse Functions
    

    A formula such as \(y = f(x)\) is a method that takes an input value \(x\) and produces a single output value \(y\text{.}\) Often we want to use the relationship in the other direction. If we know the value of \(y\text{,}\) we want to find the corresponding value of \(x\text{.}\) When there is only one possible answer \(x\text{,}\) we can think of this as a new function \(x = g(y)\text{,}\) which we call the inverse function.
    🔗
    We use the language of mapping to keep track of which variable goes in and which comes out. Writing \(f : x \mapsto y\) says that \(f\) is the function that starts with \(x\) and finds \(y\text{.}\) Writing \(g : y \mapsto x\) says that \(g\) is the function that starts with \(y\) and finds \(x\text{.}\)
    🔗

    1. Section 1: Isolating variables to find inverse functions.

    For any equation involving two variables, if we can solve to isolate one variable (say \(a\)) with a formula of the other variable (say \(b\)) on the other side, then we have identified a function \(b \mapsto a\text{.}\)
    🔗
    If we can also isolate that other variable (\(b\)) with a formula of the first (\(a\)) on the other side, then this identifies a function \(a \mapsto b\text{.}\)
    🔗
    These two identified functions will be inverse functions.
    🔗

    (a)

    Fahrenheit and Celsius temperatures are related linearly. Water freezes at \((F, C) = (32, 0)\) and boils at \((F, C) = (212, 100)\text{.}\)
    🔗
    • Find the equation for \(F = f(C)\text{.}\) What does this function do?
      🔗
      🔗
    • Find the equation for \(C = g(F)\text{.}\) What does this function do?
      🔗
      🔗
    • What temperature in degrees Fahrenheit corresponds to a temperature of 24 degrees Celsius? What happens if you use the other function on the resulting Fahrenheit temperature?

    Definition 12 Inverse function.

    For a given function \(f\text{,}\) the function \(g\) is the inverse function to \(f\) if
    🔗
    • \(f(g(x)) = x\) for every \(x\) in the domain of \(g\text{,}\) and
      🔗
      🔗
    • \(g(f(x)) = x\) for every \(x\) in the domain of \(f\text{.}\)
      🔗
      🔗
    🔗

    3. Section 3: Inverse functions and solving equations.

    What you observed is the defining property of inverse functions, as stated in the definition above.
    🔗
    Notation: We write \(f^{-1}\) as the name of the inverse function to \(f\text{.}\) The \(-1\) is read as “inverse”. It is not a power or exponent, even though that is what it looks like. In particular, \(f^{-1}(x)\) does not mean \(\frac{1}{f(x)}\text{.}\)
    🔗
    Inverse functions are a tool for solving equations. Suppose we have isolated an equation into the form \(f(u) = c\text{,}\) where \(u\) is some formula and \(c\) is a value. We may apply \(f^{-1}\) to both sides. Because \(f^{-1}(f(u)) = u\text{,}\) the function \(f^{-1}\) “cancels” or unravels the action of \(f\text{,}\) and we get \(u = f^{-1}(c)\text{.}\) Then we continue solving for the variable.
    🔗

    (a)

    Consider the equation \(\sqrt{2x - 1} = 3\text{.}\) When we work with nonnegative numbers, the squaring function and the square root function are inverses of each other.
    🔗
    • Use the method of isolation to solve for \(x\text{.}\) Where did you use inverse functions?
