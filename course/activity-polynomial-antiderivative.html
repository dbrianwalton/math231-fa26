    Worksheet Antiderivatives of Polynomials
    

    The derivative operator \(\dfrac{d}{dx}\left[\ \right]\) takes a function \(f(x)\) as its input and produces the derivative function \(f'(x)\text{.}\) If we know an object’s position as a function of time \(s(t)\text{,}\) we can find a formula for its velocity \(v(t)\text{,}\) and then a formula for its acceleration \(a(t)\text{.}\)
    🔗
    Inverse operations are a major idea in mathematics, so we ask about the reverse process. If we know the derivative, can we find the original function? Knowing the acceleration, can we recover the velocity, and then the position? Today we learn to do this for polynomials.
    🔗

    1. Section 1: Running the derivative backward.

    2. Section 2: The antiderivative of a polynomial.

    Antiderivative.

    A function \(F(x)\) is an antiderivative of \(f(x)\) if \(F'(x)=f(x)\text{.}\)
    🔗
    The derivative of a constant is \(0\text{,}\) so if \(F(x)\) is an antiderivative of \(f(x)\text{,}\) then so is \(F(x)+C\) for any constant \(C\text{.}\) That is why you could not pin down \(f(x)\) in the first task. We cannot speak of the antiderivative, so we write the whole family of antiderivatives with an arbitrary constant \(C\text{:}\)
    \begin{gather*} \int dx\left[ f(x) \right] = F(x) + C\text{.} \end{gather*}
    🔗
    🔗
    The symbol \(\displaystyle\int dx\left[\ \right]\) is the reverse of \(\dfrac{d}{dx}\left[\ \right]\text{.}\) (Later courses write this same operation as \(\int f(x)\,dx\text{.}\)) To find the rule for a single term, we compare what the derivative does to \(a x^n\) with what the antiderivative must do to undo it. The derivative performs three steps, and the antiderivative reverses each one, in reverse order.
    🔗

    The Power Rule for Antiderivatives.

    For a constant \(a\) and a power \(n=0,1,2,\dots\text{,}\)
    \begin{gather*} \int dx\left[ a x^n \right] = \frac{a}{n+1}\,x^{n+1} + C\text{.} \end{gather*}
    Step \((1')\) is the constant multiple rule, and the sum rule lets us work one term at a time. We add a single \(+C\) at the end, since a sum of constants is again an arbitrary constant. A constant term is a power with \(n=0\text{,}\) so \(\displaystyle\int dx\left[ a \right] = a x + C\text{.}\)
    🔗
    🔗

    Checking an Antiderivative.

    If \(\displaystyle\int dx\left[ f(x) \right] = F(x)+C\text{,}\) check your work by computing \(\dfrac{d}{dx}\left[ F(x) \right]\) and verifying that it matches \(f(x)\text{.}\) The \(C\) disappears when you differentiate.
    🔗
    🔗
    Here is an example, with its check.
    \begin{align*} \int dx\left[ 12x^3 - 10x + 3 \right] \amp = \frac{12}{4}x^4 - \frac{10}{2}x^2 + \frac{3}{1}x + C = 3x^4 - 5x^2 + 3x + C\\ \frac{d}{dx}\left[ 3x^4 - 5x^2 + 3x \right] \amp = 12x^3 - 10x + 3 \quad\checkmark\text{.} \end{align*}
    🔗
    Find each antiderivative, and check each answer by differentiating.
    🔗

    (a)

    \(\displaystyle \int dx\left[ 8x^3 \right]\)
    🔗
    🔗

    (b)

    \(\displaystyle \int dx\left[ 6x^2 - 4x + 7 \right]\)
    🔗
    🔗

    (c)

    \(\displaystyle \int dx\left[ 9x^2 - 5x + 4 \right]\)
    🔗
    🔗

    (d)

    \(\displaystyle \int dx\left[ (x+1)(x+3) \right]\)
    🔗
    We have no rule for a product, so what must you do to the formula first?
    🔗
    🔗

    3. Section 3: Finding a particular antiderivative.

    Sometimes we know the formula for \(f'(x)\) and also one specific value of \(f(x)\text{,}\) such as \(f(a)\) at a particular \(x=a\text{.}\) The general antiderivative could have any constant added, but the data point singles out the one constant that matches.
    🔗

    Finding a Particular Antiderivative.

    1. Find the general antiderivative \(f(x)=F(x)+C\text{,}\) keeping the symbol \(C\) in the formula.
      🔗
      🔗
    2. Evaluate the formula at \(x=a\text{,}\) with \(C\) still present, to get \(F(a)+C\text{.}\)
      🔗
      🔗
    3. Set \(F(a)+C\) equal to the known value of \(f(a)\text{,}\) and solve the equation for \(C\text{.}\)
      🔗
      🔗
    4. Write the final formula for \(f(x)\) using that particular value of \(C\text{.}\)
      🔗
      🔗
    🔗
    🔗
    Example. Find \(f(x)\) if \(f'(x)=6x^2-2\) and \(f(2)=10\text{.}\)
    \begin{align*} f(x) \amp = \int dx\left[ 6x^2 - 2 \right] = 2x^3 - 2x + C\\ f(2) \amp = 2(2)^3 - 2(2) + C = 12 + C\\ 12 + C \amp = 10 \quad\Longrightarrow\quad C = -2\\ f(x) \amp = 2x^3 - 2x - 2\text{.} \end{align*}
    Notice that \(C=-2\) is not the given value \(10\text{.}\) The data value is \(f(2)\text{,}\) which is the whole formula evaluated at \(x=2\text{,}\) and \(C\) is only one piece of it. As a check, \(f(2)=16-4-2=10\text{.}\)
    🔗

    (a)

    Find \(f(x)\) if \(f'(x)=4x^3-6x\) and \(f(1)=5\text{.}\)
    🔗
    🔗

    (b)

    Find \(f(x)\) if \(f'(x)=6x^2+4x-1\) and \(f(-2)=3\text{.}\)
