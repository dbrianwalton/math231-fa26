    Worksheet Introducing Limits and Continuity
    

    When we evaluate a function on a graph, \(f(a)\) always refers to the \(y\)-value of the closed point at \(x=a\text{.}\) Open points are not values of the function. But an open point still tells us something: it shows where the graph was headed as it approached that \(x\)-value.
    🔗
    Today we introduce a way to talk about that open point, using the idea of a limit. We will use limits to describe how a graph behaves near a point, separately from what the function value is at that point, and to name the different ways a graph can fail to be connected.
    🔗

    1. Section 1: Left- and Right-Limits.

    Here is the same function \(f\) whose graph we used when reading values from a graph.
    🔗
    Although \(f(-2) = 4\text{,}\) there is an open point at \((-2,3)\) attached to the segment of the graph defined on the domain’s subset interval \([-4,-2)\) that appears immediately to the left of \(x=-2\text{.}\) We call the \(y\)-value 3 the left-limit of \(f(x)\) as \(x\) approaches \(-2\text{.}\) We cannot use simple function evaluation to describe it, because \(f(-2)\) can only mean 4.
    🔗
    Instead, we use what is called a limit operator to act on \(f(x)\) and write
    \begin{gather*} \lim_{x \to -2^{-}} f(x) = 3\text{.} \end{gather*}
    The notation \(x \to -2\) is how we indicate which \(x\)-value we are looking at. The superscript - that appears after the value \(-2\) is how we indicate we are looking on the left side. The limit operator is acting on \(f(x)\text{,}\) and the entire notation \(\displaystyle \lim_{x \to -2^{-}} f(x)\) represents the left-limit of \(f(x)\) as \(x\) approaches \(-2\) (or as \(x\) approaches \(-2\) from the left).
    🔗
    Because the closed point at \((-2,4)\) is connected to the graph using the domain’s subset interval \((-2,-0.5)\) to the right of \(x=-2\text{,}\) we write
    \begin{gather*} \lim_{x \to -2^{+}} f(x) = 4 \end{gather*}
    and say the \(y\)-value 4 is the right-limit of \(f(x)\) as \(x\) approaches \(-2\text{.}\)
    🔗
    When we talk about a limit, we are not talking about the actual function value at a point. We are talking about the point that the function would connect to if we were to look at the domain’s subset intervals immediately to the left or right of the point. In this case, the left- and right-limits are different, and so we say “\(f(x)\) has a jump discontinuity at \(x=-2\)”.
    🔗

    2. Section 2: Two-Sided Limits and Continuity.

    Now look at \(x=-3\) on the graph of \(f\text{.}\) The graph just goes continuously through the point at \((-3,2)\text{,}\) which corresponds to \(f(-3)=2\text{.}\) Because the graph using the domain’s subset interval \([-4,-3)\) to the left of \(x=-3\) connects to the point \((-3,2)\text{,}\) we write
    \begin{gather*} \lim_{x \to -3^{-}} f(x) = 2\text{.} \end{gather*}
    Similarly, the graph for the domain’s subset interval \((-3,-2)\) to the right of \(x=-3\) is also connected to the point \((-3,2)\text{,}\) so we also write
    \begin{gather*} \lim_{x \to -3^{+}} f(x) = 2\text{.} \end{gather*}
    When the subset intervals to the left and right are both connected to the same point, the left- and right-limits have the same value, and we simply write
    \begin{gather*} \lim_{x \to -3} f(x) = 2 \end{gather*}
    without any \(\pm\) superscript after the \(x\)-value. This is called the two-sided limit.
    🔗
    In this case the left- and right-limits also agree with the actual function value \(f(-3)=2\text{,}\) and we say “\(f(x)\) is continuous at \(x=-3\)”.
    🔗
    If the left- and right-limits agree with each other but do not agree with the function value, the two-sided limit exists but the function is not continuous. We say that “\(f(x)\) has a removable discontinuity or hole” at the \(x\)-value.
    🔗
    Sometimes a limit does not exist (often abbreviated DNE). For example, if the graph has no points at all on one side of an \(x\)-value, there is nothing for the graph to connect to on that side, so that one-sided limit does not exist. The two-sided limit exists only when both one-sided limits exist and are equal.

    3. Section 3: Limits of Piecewise Functions.

    For any \(x\)-value, there are three things to compare: the left-limit, the right-limit, and the function value. Sometimes these are all the same point, and we say “\(f(x)\) is continuous” when they all agree. Otherwise, there is a discontinuity.
    🔗
    We look for the same information when using a formula instead of a graph. Consider the piecewise function
    \begin{equation*} p(x) = \begin{cases} x+3, \amp x \lt -1 \\ 5, \amp x = -1 \\ x^2+1, \amp -1 \lt x \lt 2 \\ 7-x, \amp 2 \le x \lt 4 \\ 2x-3, \amp x \ge 4 \text{.}\end{cases} \end{equation*}
    To find a function value \(p(c)\text{,}\) we choose the rule whose condition includes \(c\text{.}\) To find a left-limit at \(c\text{,}\) we use the rule that applies on the interval immediately to the left of \(c\text{,}\) and ask what \(y\)-value that rule approaches as \(x\) gets to \(c\text{.}\) To find a right-limit, we do the same with the rule on the interval immediately to the right of \(c\text{.}\) It may help to sketch a representation of the domain’s subintervals and the formulas used on each.
