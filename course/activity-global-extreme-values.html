    Worksheet Global Extreme Values
    

    We have used the sign of \(f'(x)\) to find where a function has a local maximum or a local minimum. Now we ask a different kind of question: what is the very highest or the very lowest value the function reaches over a whole set of inputs? That is the question behind finding the cheapest design, the largest area, or the greatest height. In this activity we review the tests for local extremes, then define and find global extremes.
    🔗

    1. Section 1: Two tests for local extremes.

    Recall that critical points are the only places where a local extreme can occur. Once we have a critical point, there are two ways to decide what happens there. The first is the sign chart of \(f'(x)\) that we have already used.
    🔗

    First Derivative Test for Local Extremes.

    Let \(x=a\) be a critical point of \(f(x)\text{,}\) and look at the sign chart of \(f'(x)\) around \(x=a\text{.}\)
    • If \(f'(x)\) changes from positive to negative (\(+/-\)) at \(x=a\text{,}\) then \(f(x)\) has a local maximum at \(x=a\text{.}\)
      🔗
      🔗
    • If \(f'(x)\) changes from negative to positive (\(-/+\)) at \(x=a\text{,}\) then \(f(x)\) has a local minimum at \(x=a\text{.}\)
      🔗
      🔗
    • If \(f'(x)\) does not change sign at \(x=a\text{,}\) then \(f(x)\) has neither at \(x=a\text{.}\)
      🔗
      🔗
    🔗
    🔗
    The second test uses concavity, which we measure with the second derivative \(f''(x)\text{.}\) A graph that is concave up near a horizontal tangent looks like the bottom of a bowl, and one that is concave down looks like the top of a hill.
    🔗

    Second Derivative Test for Local Extremes.

    • If \(f'(a)=0\) and \(f''(a)\) is positive (think: concave up), then \(f(x)\) has a local minimum at \(x=a\text{.}\)
      🔗
      🔗
    • If \(f'(a)=0\) and \(f''(a)\) is negative (think: concave down), then \(f(x)\) has a local maximum at \(x=a\text{.}\)
      🔗
      🔗
    If \(f''(a)=0\text{,}\) the test does not tell us anything.
    🔗
    🔗

    (a)

    Use both tests on the function \(f(x)=x^3-12x+4\text{.}\)
    1. Find \(f'(x)\text{,}\) factor it completely, and list the critical points.
      🔗
      🔗
    2. Make a sign chart of \(f'(x)\text{.}\) Use the First Derivative Test to classify each critical point, and find the \(y\)-value at each one.
      🔗
      🔗
    3. Find \(f''(x)\text{.}\) Use the Second Derivative Test to classify each critical point. Do the two tests agree?
      🔗
      🔗
    4. Which test took less work here? Describe a situation where the Second Derivative Test cannot decide, but the First Derivative Test can.
      🔗
      🔗
    🔗
    🔗
    🔗

    2. Section 2: Global extreme values.

    A local extreme only needs to be the highest or lowest value of the function in a small neighborhood surrounding that point. A global extreme is the highest or lowest value of the function over an entire specified set, such as an interval or the whole domain.
    🔗

    Global Extreme Values.

    A function \(f(x)\) has a global maximum on a set \(S\) at \(x=a\) means that \(f(a) \ge f(x)\) for all other \(x\) in \(S\text{.}\)
    🔗
    A function \(f(x)\) has a global minimum on a set \(S\) at \(x=a\) means that \(f(a) \le f(x)\) for all other \(x\) in \(S\text{.}\)
    🔗
    🔗
    Notice that \(a\) must belong to \(S\text{,}\) so the extreme value must actually be a value that the function takes. Where can such a point be? If \(a\) is an interior point of \(S\text{,}\) then \(f(a)\) is also a local extreme, so \(a\) must be a critical point. Otherwise \(a\) is on the boundary of \(S\text{.}\)
    🔗

    Strategy for Finding Global Extremes.

    1. Find the critical points of \(f(x)\) that lie inside the set. Ignore any that lie outside.
      🔗
      🔗
    2. Find the boundary points of the set. At a boundary point that is included in the set and where \(f(x)\) is continuous, find the function value \(f(a)\text{.}\) At a boundary point that is not included, or where \(f(x)\) is not continuous, find the limit of \(f(x)\) as \(x\) approaches it instead.
      🔗
      🔗
    3. Compare the \(y\)-values from steps 1 and 2 to determine the range of the function on the set.
      🔗
      🔗
    4. A global maximum or minimum exists only if the highest or lowest \(y\)-value is actually reached by a function value. A value that is only a limit is not reached.
      🔗
      🔗
    🔗
    🔗
    Example. Find the global extremes of \(f(x)=x^2\) on the set \([-1,2)\text{.}\)
    🔗
    Since \(f'(x)=2x=0\) at \(x=0\text{,}\) there is one critical point and \(f(0)=0\text{.}\) There are two boundary points. The point \(x=-1\) is included, and \(f(-1)=(-1)^2=1\text{.}\) The point \(x=2\) is not included, so we cannot use \(f(2)\text{.}\) Instead we use a limit, \(\displaystyle \lim_{x \to 2^-} x^2 = \left. (x^2) \right|_{x=2} = 4\text{.}\)
    🔗
    The value \(y=0\) is the lowest value, and \(y=4\) is the highest value, but only as a limit, so the range is \([0,4)\text{.}\) The function \(f(x)\) has a global minimum of \(0\) at \(x=0\text{,}\) but \(f(x)\) does not have a global maximum. We can reach any \(y\)-value with \(0 \le y \lt 4\text{,}\) but for every \(x\) in the set there is always another \(x\)-value closer to \(2\) that reaches an even higher value.
    🔗

    (a)

    In the example, the point \(x=-1\) gave the value \(y=1\text{,}\) which is neither the global maximum nor the global minimum. Suppose the set is changed to \([-1,2]\text{,}\) which now includes \(x=2\text{.}\) What is the range, and where are the global maximum and global minimum?
    🔗
    🔗
    🔗

    3. Section 3: The Extreme Value Theorem.

    In the example, the global maximum failed to exist because the right end of the set was not included. If the set includes both of its boundary points and the function has no breaks, that problem cannot happen.
    🔗

    Extreme Value Theorem.

    If \(f(x)\) is a continuous function on a closed interval \([a,b]\text{,}\) then \(f(x)\) will have both a global maximum and a global minimum on \([a,b]\text{.}\)
    🔗
    🔗
    When the theorem applies, we are guaranteed that the strategy above will produce a global maximum and a global minimum. We simply compare the function values at the critical points in the interval and at the two end points, and the largest and smallest of them are the global extremes. When the theorem does not apply, because the interval is not closed or the function is not continuous, we must be careful. A global extreme might exist, or might not, and we decide by finding the range.
    🔗

    (a)

    The function \(f(x)=x^2\) on \([-1,2)\) has no global maximum. Which condition of the Extreme Value Theorem fails? Then give your own example of a function that is not continuous on a closed interval \([0,2]\) and has no global maximum there.
    🔗
    🔗
    🔗

    4. Section 4: Finding the range and global extremes.

    For each function and set below, answer the following.
    1. Find \(f'(x)\text{,}\) factor it, and list the critical points that lie inside the set.
      🔗
      🔗
    2. Find the \(y\)-value at each of those critical points. Then find the \(y\)-value (a function value or a limit) at each boundary point.
      🔗
      🔗
    3. Use these \(y\)-values to state the range of the function on the set.
      🔗
      🔗
    4. State whether there is a global maximum and whether there is a global minimum. If so, give the value and the \(x\)-value where it occurs.
      🔗
      🔗
    🔗

    (a)

    \(f(x)=x^3-12x\) on the interval \([-3,5]\text{.}\)
    🔗
    🔗

    (b)

    \(f(x)=x^3-3x^2\) on the interval \([-1,3]\text{.}\)
    🔗
    🔗

    (c)

    \(f(x)=x^3-12x\) on the interval \((-3,5)\text{.}\) Compare your answers with the first task. What changed when the end points were removed?
    🔗
    🔗

    (d)

    \(f(x)=x^3-3x\) on the interval \((-3,2]\text{.}\)
    🔗
    🔗

    (e)

    \(f(x)=x^3-3x\) on the interval \((1,3)\text{.}\) Be careful about which critical points belong to the set.
    🔗
    🔗

    (f)

    \(f(x)=x^4-8x^2+10\) on the set \((-\infty,\infty)\text{.}\) The boundary of this set is the behavior of \(f(x)\) as \(x \to -\infty\) and as \(x \to +\infty\text{,}\) so use limits at infinity for those \(y\)-values. Is the local maximum a global maximum?
