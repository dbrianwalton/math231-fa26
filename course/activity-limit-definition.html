    Worksheet The Definition of a Limit
    

    The limit \(\displaystyle \lim_{x \to a} f(x)\) is a value \(L\) if the value of \(f(x)\) converges to \(L\) when \(x \to a\) from the left and right. The value of \(f(a)\) itself is not relevant. We need a way to formalize what this means. Rules of limits will eventually all be based on the definition that we choose.
    🔗
    In order to be precise, we need to be able to say what it means for \(f(x)\) to converge to a value \(L\) as \(x \to a\text{.}\) When we looked at limits using a table, we saw that the value of \(f(x)\) was becoming closer to a final value when \(x\) was getting closer to \(a\text{.}\) Limits are based on the idea of distance between values.
    🔗
    For two numbers \(x_1\) and \(x_2\text{,}\) the distance is measured as the absolute value of their difference, \(|x_1 - x_2|\text{.}\) In a limit statement, we are interested in two different distances at the same time: \(|x-a|\) measures the distance \(x\) is away from \(a\) and \(|f(x) - L|\) measures the distance \(f(x)\) is away from \(L\text{.}\)
    🔗

    Definition of a Limit.

    \(\displaystyle \lim_{x \to a} f(x) = L\) means that “for every \(\epsilon \gt 0\text{,}\) there exists some \(\delta \gt 0\) so that \(|f(x)-L| \lt \epsilon\) whenever \(0 \lt |x-a| \lt \delta\text{.}\)”
    🔗
    🔗
    Limits are really about approximation. The value of the limit \(L\) represents some value that we want to know but that in principle is something we can only approximate. The function \(f(x)\) is the rule of approximation based on choosing values of \(x\) that get progressively closer to \(a\text{.}\)
    🔗
    The inequality \(|f(x)-L| \lt \epsilon\) means \(L-\epsilon \lt f(x) \lt L+\epsilon\text{.}\) The value \(\epsilon\) represents an acceptable tolerance of error in our approximation, or how close we require \(f(x)\) to be to \(L\text{.}\) The inequality \(|x-a| \lt \delta\) means \(a-\delta \lt x \lt a+\delta\text{.}\) The additional requirement \(0 \lt |x-a|\) means \(x \ne a\text{.}\) The value \(\delta\) represents how close \(x\) needs to be to \(a\) in order to be guaranteed that \(f(x)\) is within \(\epsilon\) of \(L\text{.}\)
    🔗

    1. Section 1: Absolute Value Inequalities.

    An absolute value inequality such as \(|x-a| \lt r\) says that the distance from \(x\) to \(a\) is less than \(r\text{.}\) Equivalently, \(a-r \lt x \lt a+r\text{,}\) which is an interval centered at \(a\text{.}\)

    2. Section 2: Distance Between Function Values.

    The same idea applies to outputs. The distance between the output \(f(x)\) and the value \(L\) is \(|f(x)-L|\text{.}\) If we write \(y=f(x)\text{,}\) then the inequality \(|y-L| \lt \epsilon\) describes a horizontal strip around the line \(y=L\text{.}\) The graph of \(y=f(x)\) is inside the strip exactly for the \(x\)-values where \(|f(x)-L| \lt \epsilon\text{.}\)
    🔗
    In this section, let \(f(x) = 2x+3\) and \(L=7\text{.}\) Notice that \(f(2)=7\text{,}\) so the graph of \(y=f(x)\) crosses the line \(y=L\) at \(x=2\text{.}\)

    4. Section 4: Describing the Limit Definition.

    In the previous sections you carried out the key step of the limit definition for one choice of \(\epsilon\text{.}\) In general, the definition describes the following process, which is illustrated in Figure 26.
    🔗
    The point on the graph at \(x=a\) is drawn half-filled on purpose. The limit ignores the value of \(f(a)\text{,}\) so the point may or may not be included in the graph at \(x=a\text{.}\) Only the behavior of the graph near \(x=a\) matters.
    🔗
    • Given any value of \(\epsilon \gt 0\text{,}\) we can create the strip \(|y-L| \lt \epsilon\) and look at \(y=f(x)\) to find the set of \(x\)-values for which \(|f(x)-L| \lt \epsilon\text{.}\)
      🔗
      🔗
    • We then verify that \(x=a\) is inside an interval within this set, possibly excluding the actual value of \(a\) itself. The value \(\delta \gt 0\) represents a symmetric neighborhood \(a-\delta \lt x \lt a+\delta\) with \(x \ne a\) completely contained in the solution set of \(|f(x)-L| \lt \epsilon\text{.}\)
      🔗
      🔗
    • If this works for every positive choice for \(\epsilon\text{,}\) then the limit statement is true. If there is any value of \(\epsilon\) such that this fails to work, then the limit statement is false.
      🔗
      🔗

    (a)

    For \(f(x)=2x+3\text{,}\) \(a=2\text{,}\) and \(L=7\text{,}\) you found in Section 2 the set of \(x\)-values that works for \(\epsilon=0.2\text{.}\) What is the largest value of \(\delta\) that works? Would a smaller positive value of \(\delta\) also work? Explain.
    🔗
    🔗

    (b)

    For \(f(x)=x^2\text{,}\) \(a=2\text{,}\) and \(L=4\text{,}\) use your work in Section 3 to give a value of \(\delta\) that works for \(\epsilon=0.1\text{.}\) Then explain why \(\delta=0.03\) does not work by finding a specific \(x\) with \(|x-2| \lt 0.03\) for which \(|f(x)-4| \lt 0.1\) is false.
    🔗
    🔗

    (c)

    Suppose someone claims that \(\displaystyle \lim_{x \to 2} (2x+3) = 5\text{.}\) Test the claim with \(\epsilon = 0.2\text{.}\)
    🔗

      🔗
      🔗
    2. Is \(x=2\) inside an interval within this set? Is there any value of \(\delta \gt 0\) that works?
      🔗
      🔗
    3. What does this tell you about the claim?
      🔗
      🔗

    (d)

    Suppose someone claims that \(\displaystyle \lim_{x \to 3} \frac{2}{x} = 0.6\text{.}\) Test the claim with two different tolerances, using a graph or by solving the inequalities.
    🔗
    1. For \(\epsilon = 0.1\text{,}\) find the set of \(x\)-values for which \(\left| \frac{2}{x} - 0.6 \right| \lt 0.1\text{.}\) Is \(x=3\) inside an interval within this set? If so, give a value of \(\delta\) that works.
      🔗

    2. For \(\epsilon = 0.05\text{,}\) find the set of \(x\)-values for which \(\left| \frac{2}{x} - 0.6 \right| \lt 0.05\text{.}\) Is \(x=3\) inside an interval within this set? Is there any value of \(\delta \gt 0\) that works?
      🔗
      🔗
